# VIBE EMS Training - موقع إلكتروني احترافي

## نظرة عامة على المشروع

موقع إلكتروني احترافي ومتكامل لمركز VIBE EMS Training، مصمم ليكون أداة تسويقية قوية وفعالة تعكس رؤية المركز ورسالته في تقديم تدريبات EMS المتطورة في مصر.

## المميزات الرئيسية

### 🎨 التصميم والواجهة
- **تصميم عصري وجذاب**: يعكس روح الابتكار واللياقة البدنية
- **ألوان احترافية**: درجات الأزرق والرمادي مع لمسات من الألوان الزاهية
- **تصميم متجاوب**: يتناسب مع جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- **تجربة مستخدم ممتازة**: تصفح سلس وبديهي

### 📱 الوظائف الأساسية
- **نظام حجز مواعيد متكامل**: يسمح للعملاء بحجز الجلسات بسهولة
- **نموذج اتصال فعال**: للتواصل المباشر مع المركز
- **خرائط جوجل**: لتحديد موقع المركز
- **روابط وسائل التواصل الاجتماعي**: لزيادة التفاعل
- **زر واتساب مباشر**: للتواصل السريع

### 🎯 الأقسام الرئيسية
1. **الصفحة الرئيسية**: عرض شامل للمركز وخدماته
2. **عن المركز**: قصة المركز وفريق العمل
3. **تقنية EMS**: صفحة مخصصة لشرح التقنية وفوائدها
4. **خدماتنا**: شرح تفصيلي لخدمات EMS
5. **فوائد EMS**: مميزات التقنية وفوائدها
6. **آراء العملاء**: شهادات وتجارب العملاء
7. **الأسعار**: باقات متنوعة ومنافسة
8. **حجز موعد**: نظام حجز سهل ومتطور
9. **اتصل بنا**: معلومات التواصل والموقع

## التثبيت والتشغيل

### المتطلبات الأساسية
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- خادم ويب محلي (اختياري للتطوير)

### خطوات التثبيت

1. **تحميل المشروع**
   ```bash
   git clone [repository-url]
   cd vibe-ems-website
   ```

2. **إضافة الصور**
   - قم بإنشاء مجلد `images/`
   - أضف الصور المطلوبة (انظر قائمة الصور أعلاه)

3. **تشغيل الموقع**
   - افتح ملف `index.html` في المتصفح
   - أو استخدم خادم محلي:
   ```bash
   python -m http.server 8000
   # ثم افتح http://localhost:8000
   ```

## التخصيص والتعديل

### تغيير الألوان
يمكن تعديل الألوان من خلال متغيرات CSS في ملف `css/style.css`:

```css
:root {
    --primary-color: #2563eb;    /* اللون الأساسي */
    --secondary-color: #1e40af;  /* اللون الثانوي */
    --accent-color: #f59e0b;     /* لون التمييز */
    /* ... باقي الألوان */
}
```

### تعديل المحتوى
- **النصوص**: تعديل مباشر في ملف `index.html`
- **الصور**: استبدال الصور في مجلد `images/`
- **معلومات الاتصال**: تحديث في قسم "اتصل بنا"

### إضافة صفحات جديدة
1. إنشاء ملف HTML جديد
2. إضافة الرابط في القائمة الرئيسية
3. تحديث ملف CSS إذا لزم الأمر
